I'm a passionate software engineer and architect, specialising in node.js, React and distributed systems.

I'm the lead maintainer for the [Terser](https://terser.org/) JS minifier. The project is funded on OpenCollective. Would you like to [contribute](https://opencollective.com/terser)?
